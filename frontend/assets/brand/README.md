# FaFo brand art

From the client's Drive folder (1 Nov 2026).

- `mascot.svg` — the dinosaur alone (blue). Same shape as the notification
  art: `android/app/src/main/res/drawable/ic_stat_fafo.xml` (white silhouette)
  and `drawable-nodpi/fafo_notification_tile.png` (blue tile).
- `logo-light.svg` — blue dino on a white tile, ink outline + offset shadow.
- `logo-dark.svg` — white dino on a blue tile, ink outline + offset shadow.

The files use the old blue `#1A87DA`; the design guide's FaFo blue is
`#1A6FD0`. Recolour when using them in the app.

`design/brand/hero.png` (repo root, not bundled) is a 5754×4474 marketing
visual of the older app, for the store listing / website.

Not yet decided: whether the mascot replaces the app icon, splash and the
header "F" mark (brief 2.6 says yes; the 1 Nov design still shows the "F").
